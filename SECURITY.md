# Security Policy

## Supported version

Security fixes apply to the latest revision on the default branch.

## Reporting

Do not open a public issue for vulnerabilities that could expose credentials, private lead data, contracts or customer communications. Contact the repository owner privately through their GitHub profile.

## Sensitive data

Never commit:

- API keys, tokens or passwords;
- real CRM databases or lead exports;
- private WhatsApp or email conversations;
- signed contracts, personal documents or payment evidence;
- customer assets without permission.

Use synthetic data in examples and tests.
